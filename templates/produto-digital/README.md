# Template de produto digital

Rascunho reutilizável para uma nova landing page de PDF, curso ou material
próprio. Esta pasta não é uma página publicada e não entra no catálogo até
ser copiada para uma pasta de produto real.

## Como usar

1. Copie a pasta para um slug novo, por exemplo `meu-novo-produto/`.
2. Edite `product.json` com nome, idioma, preço e descrição.
3. Cadastre a mesma pasta no CMS em **Produtos**.
4. Escolha Hotmart, Cakto, Kiwify ou próprio/outro e informe o checkout HTTPS.
5. Informe o pixel Meta do produto ou deixe vazio.
6. Só depois de testar a prévia publique o produto.

A landing chama o mesmo runtime de checkout/pixel usado pelas páginas atuais.
Os placeholders `#checkout-pending-funil-b3` permanecem inofensivos até o
produto ter uma oferta configurada.
